================================================================================
0. PRODUCT INTENT (what "working" means)
================================================================================

nuckyAI is the paid SaaS moat: an analyst that reads the same tier-1 data the
dashboard shows, plus external context (Liquipedia, patch notes, Reddit threads,
Kalshi odds, schedules). Users should be able to:

  - Ask natural-language questions about players, teams, champions, matchups, meta
  - Get numbers that match the dashboard for the same league/split filter
  - Receive external narrative context when RAG has relevant chunks (with source attribution)
  - See radar/compare charts inline when comparing entities
  - Trust that empty data → honest "no data" rather than invented stats

Success criteria (post-fix):
  - Golden question set pass rate >= 85% (see Section 5)
  - Zero subscription desync between nav and paywall
  - Distinct, actionable error messages for auth / quota / server failures
  - RAG index fresh within 7 days; documents table non-empty for tier-1 leagues

2. KNOWN BUGS & FAILURE MODES
================================================================================

CLIENT (fixable in public repo)

  [C1] Subscription gate mismatch
       NuckyAIContainer checks profiles.is_subscribed only.
       Layout.tsx also checks subscriptions table (active/trialing).
       Symptom: user passes nav but hits paywall, or reverse.

  [C2] Generic error swallowing
       useAgentChat.ts maps all failures to "nuckyAI is taking a nap."
       Symptom: 401/403/429/500 indistinguishable; impossible to self-diagnose.

  [C3] Regenerate duplicates messages
       send() always appends new user + assistant pair; regenerate re-sends without
       removing prior assistant turn.
       Symptom: duplicate user messages and stacked assistant replies.

  [C4] No stream cancel
       useAgentChat exports stop() but NuckyAIContainer never wires it.
       Symptom: user stuck waiting on long/broken streams.

  [C5] Chart parse flicker
       MessageBubble regex-parses ```chart during streaming; partial JSON may flash.
       Symptom: raw JSON visible mid-stream.

  [C6] Silent message load failures
       loadMessages logs to console only; user sees empty chat.

  [C7] Narrow filter context
       Only league + split sent; multi-league "All Tier 1" or cross-split questions
       may not match backend tool semantics.

BACKEND (requires private source or Supabase dashboard access)

  [B1] Tool router gaps
       Intent → tool mapping may miss common question types; LLM guesses without data.

  [B2] OE tool vs dashboard drift
       Backend tools query oe_slices; dashboard computes via mergeSlices.ts + src/lib/*.
       Symptom: AI cites different winrate/KDA than UI for same filter.

  [B3] RAG empty or stale
       documents table empty, indexer not run, or match_documents RPC param mismatch.
       Symptom: no external context; hallucinated narrative.
       Reference: scripts/recap/rag.ts shows fallback param shapes for match_documents.

  [B4] Schedule tool not wired / stale esports_schedules
       Symptom: "when does T1 play next" fails or returns old dates.

  [B5] Prompt allows hallucination when tools return empty
       Symptom: confident wrong facts instead of "no data for this filter."

  [B6] Usage quota opaque
       agent_usage_events may block requests; client shows generic nap message.

  [B7] Private source missing locally
       Cannot edit prompts/tools without backup recovery.

5. GOLDEN QUESTION SET (eval framework)
================================================================================

Run each prompt with dashboard filter: League = LCK (or ALL Tier 1), Split = current.
Record: PASS | FAIL | PARTIAL. Note failure class (C1–C7, B1–B7).

  CATEGORY: Player stats
    1. "What is Chovy's KDA this split?"
    2. "Who has the best GD@15 among LCK mid laners?"
    3. "Compare Faker and Zeka — radar chart"

  CATEGORY: Team stats
    4. "How is T1's winrate this split?"
    5. "Which LCK team has the best objective control?"
    6. "Compare Gen.G and HLE"

  CATEGORY: Champion meta
    7. "What are the most picked champions in LCK right now?"
    8. "Is Ahri meta in LPL this split?"

  CATEGORY: Matchup
    9. "T1 vs Gen.G head to head this split"
   10. "Lane matchup: Kiin vs Zeus"

  CATEGORY: Schedule
   11. "When does T1 play next?"
   12. "What's on the LCK schedule this week?"

  CATEGORY: External / RAG
   13. "What changed in the latest patch for ADC items?"
   14. "What did Reddit say about the last GEN vs HLE series?"
   15. "Kalshi odds for today's LCK matches" (if indexed)

  CATEGORY: Edge cases
   16. "Best support in CBLOL" (wrong league — should say no data or clarify filter)
   17. "Faker stats" with LPL filter selected (should disambiguate or note mismatch)
   18. Empty/novel player name "xyzplayer123" (should not invent stats)
   19. "Who won MSI 2026?" (may need RAG; must not hallucinate if no data)
   20. Cross-split: "T1 winrate in 2025 vs 2026" (may exceed tool capability — honest answer)

  PASS definition:
    - Numbers match dashboard within rounding (±0.1 for rates, ±1 for raw counts)
    - Compare questions include chart or explicit stat table
    - No invented players, teams, or scores
    - External questions cite or imply external source; admit gap if RAG empty

  Track in spreadsheet or markdown log:
    date | prompt | filter | expected | actual | pass/fail | failure class | notes

  Re-run full set after every agent-chat deploy.
