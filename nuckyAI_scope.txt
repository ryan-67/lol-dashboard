================================================================================
0. PRODUCT INTENT
================================================================================

## What nucky is

nucky is the named analyst character behind nucky.gg and nuckyAI. Users say
"hey nucky" or share takes as "nucky made this matchup analysis."

Persona:
  - blunt 20-something lolesports fan in 2026
  - casual, lowercase, meme-literate (diff, int, grief, goat, 1v9, malding, etc.)
  - not afraid to call players/teams bums or frauds when stats back it
  - hyperbolic praise when earned
  - never corporate; never mentions Oracle's Elixir, OE, RAG, database, tools

## What nucky should do

  - Hold fluid multi-turn conversation like a normal AI agent within lolesports
  - Refuse off-topic requests cleanly ("i'm nucky — lolesports only")
  - Answer simple stat asks in text ("chovy's kda?")
  - Generate inline charts for comparisons/matchups (radar, line/bar when relevant)
  - Ground numeric claims in verified match data (oe_slices via tools)
  - Use RAG + world calendar + LLM knowledge for tournaments, qualifiers, meta,
    patch notes, Reddit, Kalshi — without inventing per-game stats
  - Respect real-world time (client_now): e.g. MSI 2026 not "already over" before
    June 28, 2026
  - Match dashboard numbers for the same league/split/year filter

## What nucky is NOT (yet)

  - Live in-game telemetry (GRID pending approval)
  - Solo queue / op.gg style data
  - General-purpose assistant (coding, recipes, homework, etc.)

## Success criteria

  - Golden question set >= 85% pass (see Section 6 + nuckyAI_eval_log.md)
  - No temporal hallucinations (MSI status, invented series KDA lines)
  - Compare/matchup questions include charts when appropriate
  - Dashboard filter alignment (header → chat request body)
  - Subscription gate matches billing state
  - RAG index fresh within ~7 days when indexer runs

REQUEST FLOW (agent-chat edge function)

  1. Auth (Supabase JWT) + subscription check (profiles)
  2. Quota (agent_usage_events) — 25/day, 750/month; SSE error on exceed
  3. resolveConversation + SSE metadata (conversation_id)
  4. buildTemporalContext(client_now) → WORLD_CONTEXT block
  5. classifyScope(message, history)
       off_topic → refusal stream, done
  6. If needs_tools: buildAnalystContext → MATCH_STATS tools (no always-on snapshot)
  7. If compare intent: runTeamCompare / runPlayerCompare → stream ```chart radar first
  8. classifyIntent → optional sqlQuery, vectorSearch (RAG)
  9. finalMessages or chatOnlyMessages → OpenRouter stream (MODEL_SIMPLE / MODEL_COMPLEX)
  10. persist user + assistant to messages table

2. IMPLEMENTED TOOLS & CAPABILITIES
================================================================================

Deterministic tools (oe_slices / esports_schedules):
  player_stat           — single player KDA, GD@15, etc.
  team_stat             — winrate, record
  team_rankings         — objective control, winrate leaders
  team_roster           — who's on DK / T1 / etc.
  series_recap          — gameLog-ordered series (no invented reverse sweeps)
  champion_pool_compare — split-scoped pools from oe data
  matchup_lookup        — H2H from matchups table
  player_rankings       — role/league composite rankings
  champion_meta         — picks/presence/winrate
  team_form             — last-5 from game logs
  lane_matchup          — positional comparison two teams
  schedule_lookup       — esports_schedules

Charts (server-streamed before LLM prose):
  team_compare          — dual-team radar (teamCompare.ts)
  player_compare        — dual-player radar (playerCompare.ts)
  LLM may emit ```chart JSON for line/bar when appropriate (not for compares)

Scope routing (scope.ts):
  off_topic             — refuse non-lolesports
  lolesports_chat       — casual fan talk, no forced tools
  lolesports_general    — MSI qualifiers, predictions, tournament news → RAG + WORLD
  lolesports_stats      — numeric tools required
  lolesports_compare    — tools + radar charts
  lolesports_series     — series_recap + RAG; widen split fetch; no fake per-game stats

World context (worldContext.ts) — curated, update when calendar changes:
  MSI 2026: Daejeon, June 28 – July 12, 2026
  LCK: HLE (bracket), T1 (play-in); Gen.G did NOT qualify
  LCK Road to MSI: T1 beat Gen.G 3-2 in lower bracket final
  Full bracket/play-in team lists for all regions
  temporal_rules: block "MSI already happened" before start date

Prompt contract (prompts.ts):
  - Identity: "nucky" not "nuckyAI" or "assistant"
  - MATCH_STATS = only source for numeric pro stats
  - EXTERNAL_CONTEXT = narrative; cannot override stats
  - WORLD_CONTEXT = dates, qualifiers, temporal guardrails
  - Never expose OE/RAG plumbing to users

6. GOLDEN QUESTION SET
================================================================================

Default filter: LCK, 2026 Spring (or current split). Re-run after every deploy.

  STATS
    1. What is Chovy's KDA this split?
    2. Who has the best GD@15 among LCK mid laners?
    3. How is T1's winrate this split?
    4. Which LCK team has the best objective control?

  COMPARE + CHARTS
    5. Compare Faker and Zeka — radar chart
    6. Compare Gen.G and HLE
    7. Lane matchup: Kiin vs Zeus

  META / CHAMPIONS
    8. What are the most picked champions in LCK right now?
    9. Is Ahri meta in LPL this split?

  MATCHUP / SERIES
   10. T1 vs Gen.G head to head this split
   11. What happened in the latest T1 vs Gen.G series?

  SCHEDULE
   12. When does T1 play next?
   13. What's on the LCK schedule this week?

  TOURNAMENT / WORLD CONTEXT (new — post 2026-06-18)
   14. Which LCK teams qualified for MSI 2026?
   15. Who's the favorite to win MSI 2026?
   16. Has MSI 2026 started yet?

  EXTERNAL / RAG
   17. What changed in the latest patch for ADC items?
   18. What did Reddit say about the last GEN vs HLE series?
   19. Kalshi odds for today's LCK matches

  EDGE CASES
   20. Best support in CBLOL (no data — honest answer)
   21. Faker stats with LPL filter (disambiguate)
   22. xyzplayer123 stats (no invented stats)
   23. Write me a python script (off-topic refusal)
   24. compare ruler vs gumayusi champion pools 2026 spring lck

  PASS rules:
    - Stats match dashboard ± rounding
    - Compares include radar chart
    - No OE/RAG/database mentions in user-facing text
    - No invented game-level stats
    - MSI temporal answers consistent with client_now
    - Off-topic refused in one sentence

  Log: nuckyAI_eval_log.md
